<section><h2 id="足迹页面功能概览">足迹页面功能概览</h2><p>足迹页面（<code>/life/places/</code>）以高德地图为核心，直观展示我去过的所有地方。主要功能包括：</p><ul>
<li><strong>智能标记聚类</strong>：地图缩小时自动将相近的标记聚合为圆形数字标记，放大后展开为独立标记</li>
<li><strong>区域高亮联动</strong>：点击标记时自动高亮对应省份区域，支持切换高亮模式</li>
<li><strong>分类筛选</strong>：左上角分类列表根据标签自动生成，点击可筛选不同类别的地点</li>
<li><strong>信息弹窗</strong>：点击任意标记展示地点名称、日期、描述、照片等信息</li>
<li><strong>主题适配</strong>：地图自动跟随博客明暗主题切换</li>
<li><strong>响应式设计</strong>：适配桌面和移动端</li>
</ul></section>

<section><h2 id="添加新足迹">添加新足迹</h2><p>要添加新的足迹记录，只需在 <code>src/content/life/places/</code> 目录下创建一个新的 Markdown 文件，按照上述格式填写 frontmatter 即可。</p><p>文件命名建议使用日期开头，例如：<code>2026-07-11-河南商丘.md</code>。</p><section><h3 id="坐标获取">坐标获取</h3><p>获取经纬度坐标的方式：</p><ol>
<li><strong>高德坐标拾取器</strong>：访问 <a href="https://bs.amap.com/tools/picker" target="_blank" rel="noopener noreferrer">高德坐标拾取器</a>，搜索地点后复制坐标</li>
<li><strong>高德地图 API</strong>：如果已开通 Web 服务 API 权限，可通过地理编码接口批量获取</li>
</ol><blockquote><p>坐标格式为 GCJ-02（高德坐标系），直接使用高德获取的坐标即可。</p></blockquote></section></section>
