<section><h2 id="前言">前言</h2><p>博客已经有了友链页面，但只能看到朋友们的博客链接，不能看到他们最近发了什么文章。于是想找一个「朋友圈」功能，能自动抓取好友的最新文章并展示。</p><p>经过调研，发现了 <a href="https://github.com/Rock-Candy-Tea/hexo-circle-of-friends" target="_blank" rel="noopener noreferrer">hexo-circle-of-friends</a> 这个项目。虽然名字里有 “hexo”，但它实际上是一个<strong>独立的后端服务</strong>，不依赖 Hexo，任何博客框架都能用。</p></section>
<section><h2 id="项目简介">项目简介</h2><p>hexo-circle-of-friends 的核心功能：</p><ul>
<li>🔄 <strong>定时抓取</strong>：通过 RSS/Atom 或 HTML 爬虫自动获取好友的最新文章</li>
<li>📊 <strong>统计数据</strong>：友链总数、活跃数、文章数</li>
<li>🤖 <strong>AI 摘要</strong>：支持 Gemini、SiliconFlow、智谱等 AI 生成文章摘要（可选）</li>
<li>📦 <strong>Simple Mode</strong>：输出静态 JSON 文件，无需后端服务</li>
</ul><section><h3 id="技术栈">技术栈</h3><ul>
<li>核心：Rust（爬虫 + API）</li>
<li>数据库：SQLite / MySQL / MongoDB</li>
<li>部署：GitHub Actions / Vercel / 自托管 / Docker</li>
</ul></section></section>
