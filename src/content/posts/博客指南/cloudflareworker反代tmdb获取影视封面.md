<section><h2 id="第二步绑定自己的域名">第二步：绑定自己的域名</h2><p>Worker 默认的 <code>xxx.workers.dev</code> 域名在国内同样是时通时不通，<strong>必须绑自定义域名</strong>：</p><ol>
<li>进入刚创建的 Worker 页面 → <strong>设置</strong> → <strong>域和路由</strong></li>
<li><strong>添加</strong> → <strong>自定义域</strong> → 填 <code>tmdb.0824.uk</code>（换成你的域名）</li>

<section><h2 id="经验总结">经验总结</h2><ol>
<li><strong>先诊断再动手</strong>：用 curl 分域名逐个测，搞清楚是全不通还是半通。我这台服务器图片 CDN 本来就是通的，反代只做 API 也可以，两个都代理是为了统一走缓存</li>
<li><strong><code>curl -s</code> 会吞错误</strong>：测试连通性时务必看有没有输出，空输出 = 没连上，别误判成”接口返回空”</li>
<li><strong>workers.dev 别直接用</strong>：国内基本不可达，绑自定义域名是必须的</li>
<li><strong>自定义域名要在 CF 托管</strong>：DNS 在别处（宝塔/阿里云）的域名绑不了 Worker</li>
<li><strong>缓存白送性能</strong>：TMDB 的海报和搜索结果基本不变，Worker 加一行 <code>Cache-Control</code> 一天缓存，热门内容第二次起毫秒级响应</li>
<li><strong>成本为零</strong>：Worker 免费额度每天 10 万次请求，个人项目根本用不完；域名要求一个托管在 CF 的域名即可</li>
<li><strong>反代其他被墙 API</strong>：把代码里的 <code>target</code> 换成目标 API 域名，就是一套通用方案——比如各种 AI API、图片服务，同样的套路</li>
</ol><p>至此，微信里发 <code>/影视 片名</code>，封面秒回，博客影视页自动更新，全链路不再看墙的脸色。</p></section>
