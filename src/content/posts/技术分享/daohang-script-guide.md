<section><h2 id="前言">前言</h2><p>博客的「网站导航」页面（<code>/projects/</code>）收录了大量常用网站，每个网站都需要手动创建 Markdown 文件、填写 frontmatter、找图标链接……重复操作非常繁琐。</p><p>为了解决这个问题，我开发了 <code>add-daohang</code> 脚本，<strong>只需输入一个网址，就能自动完成所有工作</strong>。</p><hr></section>
<section><h2 id="功能概览">功能概览</h2>

<table><thead><tr><th>功能</th><th>说明</th></tr></thead><tbody><tr><td>🌐 自动获取 ICO</td><td>输入网址后自动调用 API 获取网站图标</td></tr><tr><td>📝 交互式填写</td><td>逐项引导填写名称、描述、分类、标签等</td></tr><tr><td>🔍 URL 查重</td><td>检测网址是否已存在，避免重复添加</td></tr><tr><td>✏️ 编辑模式</td><td>查重后可选择编辑已有条目，更新信息或修复失效图标</td></tr><tr><td>📂 智能分类</td><td>自动扫描已有分类 + 预设分类，支持创建新分类</td></tr><tr><td>🎨 颜色选择</td><td>9 种预设颜色，也可输入自定义色值</td></tr><tr><td>📊 自动排序</td><td>自动分配 <code>order</code> 值，新条目排在最后</td></tr></tbody></table><hr></section>
