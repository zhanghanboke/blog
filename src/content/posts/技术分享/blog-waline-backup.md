<blockquote><p>数据库只有一个 SQLite 文件，丢了就真没了。写个脚本每天自动备份到 GitHub 私有仓库，安心。</p></blockquote>
<section><h2 id="背景">背景</h2><p>Waline 默认使用 SQLite 存储数据，整个数据库就是一个 <code>waline.sqlite</code> 文件。好处是轻量、不需要额外装数据库；坏处是文件丢了就什么都没了。</p><p>虽然服务器有快照功能，但快照是整个系统的，恢复起来太重。不如写个脚本，每天把关键文件打包推到 GitHub，恢复的时候一条命令搞定。</p></section>
<section><h2 id="思路">思路</h2><ol>
<li>把 <code>data/</code> 目录（SQLite 数据库）和 <code>docker-compose.yml</code> 打包成 <code>.tar.gz</code></li>
<li>推送到 GitHub 私有仓库</li>
<li>用 crontab 每天凌晨 3 点自动执行</li>
<li>本地只保留最近 7 份，GitHub 保留 30 天</li>
</ol></section>
<section><h2 id="准备工作">准备工作</h2><section><h3 id="创建-github-私有仓库">创建 GitHub 私有仓库</h3><p>去 <a href="https://github.com/new" target="_blank" rel="noopener noreferrer">GitHub</a> 新建一个仓库，<strong>一定要选 Private</strong>。名字随意，比如 <code>waline-backup</code>。</p></section><section><h3 id="生成-github-token">生成 GitHub Token</h3><ol>
<li>打开 <a href="https://github.com/settings/tokens?type=beta" target="_blank" rel="noopener noreferrer">GitHub Fine-grained tokens</a></li>
<li>点 <strong>Generate new token</strong></li>
<li>Repository access 选 <strong>Only select repositories</strong>，勾选刚创建的仓库</li>
<li>Repository permissions → <strong>Contents</strong> → 选 <strong>Read and write</strong></li>
<li>生成并保存 Token</li>
</ol><blockquote><p>⚠️ Token 只会显示一次，务必保存好。如果泄露了，立刻去 GitHub 撤销。</p></blockquote></section></section>
