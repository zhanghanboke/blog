<section><h1 id="day01">🔓Day01</h1><section><h2 id="词根radi">词根：radi​</h2><p>核心含义：根（联想“抓地”的谐音记忆法）</p><p>引申义：由“根”引申为光线、辐射（如同树根向四周延伸）<br>
词缀辅助：<br>
后缀（如 -ate​ 表动词，-ant​ 表形容词，-ion/-um​ 表名词）</p>

<table><thead><tr><th align="left">单词</th><th align="left">词性</th><th align="left">中文释义</th><th align="left">拆解与记忆逻辑</th></tr></thead><tbody><tr><td align="left">radical</td><td align="left">adj.</td><td align="left">根本的；彻底的</td><td align="left">​radi​ (根) + -cal​ (形容词后缀) → 从“根”上的 → 根本的、彻底的</td></tr><tr><td align="left">eradicate</td><td align="left">v.</td><td align="left">根除</td><td align="left">​e-​ (前缀：出/除去) + radi​ (根) + -ate​ (动词后缀) → 把根拔出来 → 根除、消灭</td></tr><tr><td align="left">radiate</td><td align="left">v.</td><td align="left">辐射；发散；使显现</td><td align="left">​radi​ (根/光线) + -ate​ (动词后缀) → 像根/光线一样向外扩散 → 辐射、散发</td></tr><tr><td align="left">radiant</td><td align="left">adj.</td><td align="left">辐射的；容光焕发的</td><td align="left">​radi​ (光线) + -ant​ (形容词后缀) → 向外散发着光的 → 容光焕发的、灿烂的</td></tr><tr><td align="left">radio</td><td align="left">n.</td><td align="left">收音机</td><td align="left">​radi​ (辐射/无线电波) + -o​ (名词后缀) → 利用无线电波（辐射）传播声音的设备</td></tr><tr><td align="left">radioactive</td><td align="left">adj.</td><td align="left">放射性的</td><td align="left">​radio​ (辐射) + active​ (活跃的) → 具有活跃辐射特性的 → 放射性的</td></tr><tr><td align="left">radium</td><td align="left">n.</td><td align="left">镭</td><td align="left">​radi​ (辐射) + -um​ (化学元素名词后缀) → 一种具有强放射性的化学元素</td></tr></tbody></table></section></section>
<section><h1 id="day02">🔓Day02</h1><section><h2 id="词根pose">词根：pose​</h2><p>核心含义：摆放（联想“摆pose”的日常场景）</p><p>引申义：由“摆放”引申为放置、姿态、构成、提出等与“放置/安排”相关的含义<br>
词缀辅助：结合之前学过的：<br>
前缀（如 ex-​ 向外、com-​ 共同、pro-​ 向前、dis-​ 分开、op-​ 相反、de-​ 向下/除去）<br>
后缀（如 -it​, -ition​, -ent​ 等）</p>

<table><thead><tr><th align="left">单词</th><th align="left">词性</th><th align="left">中文释义</th><th align="left">拆解与记忆逻辑</th></tr></thead><tbody><tr><td align="left">expose</td><td align="left">v.</td><td align="left">暴露；揭露；使显露</td><td align="left">​ex-​ (向外) + pose​ (摆放) → 把东西摆到外面 → 暴露、揭露</td></tr><tr><td align="left">compose</td><td align="left">v.</td><td align="left">组成；创造；创作</td><td align="left">​com-​ (共同) + pose​ (摆放) → 把各部分摆在一起 → 组成、创作（如作曲/作文）</td></tr><tr><td align="left">composition</td><td align="left">n.</td><td align="left">作文；作品；作曲</td><td align="left">​compos(e)​ (组成/创作) + -ition​ (名词后缀) → 创作的成果 → 作文、作品</td></tr><tr><td align="left">composite</td><td align="left">adj.</td><td align="left">复合的；合成的</td><td align="left">​compos(e)​ (组成) + -ite​ (形容词/名词后缀) → 由多部分组成的 → 复合的</td></tr><tr><td align="left">propose</td><td align="left">v.</td><td align="left">求婚；提名；提议</td><td align="left">​pro-​ (向前) + pose​ (摆放) → 把想法/计划摆到前面 → 提议、求婚</td></tr><tr><td align="left">dispose</td><td align="left">v.</td><td align="left">扔掉；处理；安排</td><td align="left">​dis-​ (分开/离开) + pose​ (摆放) → 把东西摆到别处/移走 → 处理、扔掉</td></tr><tr><td align="left">oppose</td><td align="left">v.</td><td align="left">反对</td><td align="left">​op-​ (相反) + pose​ (摆放) → 摆到对面/对立位置 → 反对</td></tr><tr><td align="left">opponent</td><td align="left">n.</td><td align="left">敌人；对手</td><td align="left">​oppos(e)​ (反对) + -ent​ (表人的名词后缀) → 反对者 → 对手、敌人</td></tr><tr><td align="left">depose</td><td align="left">v.</td><td align="left">废除；罢免</td><td align="left">​de-​ (向下/除去) + pose​ (摆放) → 把某人从位置上放下来 → 罢免、废除</td></tr><tr><td align="left">deposit</td><td align="left">n.</td><td align="left">沉淀物；定金</td><td align="left">​de-​ (向下) + pos(e)​ (摆放) + -it​ → 向下放置的东西 → 沉淀物；存放的钱（定金）</td></tr></tbody></table></section></section>
<section><h1 id="day03">🔓Day03</h1><section><h2 id="词根verst">词根：vers(t)​</h2><p>核心含义：转（联想“转动的快速声响”）</p><p>引申义：由“转”引申为转变、转移、反转、转向等与“方向/状态改变”相关的含义<br>
词缀辅助：前缀（如 re-​ 向后、a-​ 离开、con-​ 共同、di-​ 分开、intro-​ 向内、extro-​ 向外、ann(i)-​ 年、contro-​ 相反）</p>

<table><thead><tr><th align="left">单词</th><th align="left">词性</th><th align="left">中文释义</th><th align="left">拆解与记忆逻辑</th></tr></thead><tbody><tr><td align="left">reverse</td><td align="left">v.</td><td align="left">扭转；颠倒</td><td align="left">​re-​ (向后/相反) + verse​ (转) → 向反方向转 → 扭转、颠倒</td></tr><tr><td align="left">avert</td><td align="left">v.</td><td align="left">转移（注意力）；避免</td><td align="left">​a-​ (离开) + vert​ (转) → 把目光/危险转开 → 转移、避免</td></tr><tr><td align="left">convert</td><td align="left">v.</td><td align="left">转变；换算；改变信仰</td><td align="left">​con-​ (加强/共同) + vert​ (转) → 彻底转变形态/立场 → 转变、改信</td></tr><tr><td align="left">divert</td><td align="left">v.</td><td align="left">转移；改道（注意力）</td><td align="left">​di-​ (分开/偏离) + vert​ (转) → 转离原方向 → 转移、改道</td></tr><tr><td align="left">introvert</td><td align="left">n./adj.</td><td align="left">内向的人；内向的</td><td align="left">​intro-​ (向内) + vert​ (转) → 性格转向内心 → 内向的人/性格</td></tr><tr><td align="left">extrovert</td><td align="left">n./adj.</td><td align="left">外向的人；外向的</td><td align="left">​extro-​ (向外) + vert​ (转) → 性格转向外部 → 外向的人/性格</td></tr><tr><td align="left">anniversary</td><td align="left">n.</td><td align="left">周年纪念</td><td align="left">​anni-​ (年) + vers​ (转) + -ary​ (名词后缀) → 时间转了一年 → 周年纪念</td></tr><tr><td align="left">controversy</td><td align="left">n.</td><td align="left">争论；争吵；争议</td><td align="left">​contro-​ (相反) + vers​ (转) + -y​ (名词后缀) → 观点转向对立 → 争论、争议</td></tr></tbody></table></section></section>
<section><h1 id="day04">🔓Day04</h1><p>词根：press​</p><p>核心含义：压（联想“按压、挤压”的动作，直观记忆词根含义）</p><p>引申义：由“压”进一步引申为压缩、按压、抑制、表达等与“施加压力/按压”相关的含义<br>
词缀辅助：前缀（如 com-​ 共同、de-​ 向下、sup-​ 向下/在下面、im-​ 进入/使…、ex-​ 向外、re-​ 回/向后）</p>
