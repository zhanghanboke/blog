<section><h2 id="什么是-github-gist">什么是 GitHub Gist？</h2><p>GitHub Gist 是 GitHub 提供的一个轻量级代码和文本分享服务。每个 Gist 本质上是一个 Git 仓库，可以包含一个或多个文件，支持版本控制、克隆和 Fork。</p><p>Gist 分为两种类型：</p><ul>
<li><strong>Public Gist</strong>：公开可见，任何人都能搜索和访问</li>
<li><strong>Secret Gist</strong>：不会出现在搜索结果中，但知道 URL 的人仍可访问</li>
</ul><blockquote><p>注意：Secret Gist 并不是真正的”私有”，它只是不被搜索引擎索引。如果你需要真正的私有存储，请使用 Private 仓库。</p></blockquote><p>Gist 非常适合存储小规模的结构化数据，比如 JSON 格式的配置、笔记、日志等。而且它完全免费，没有存储空间限制（单文件建议 1MB 以内），API 调用频率限制为每小时 5000 次（认证后）。</p></section>
<section><h2 id="为什么选择-gist-做存储">为什么选择 Gist 做存储？</h2><p>作为一个静态博客（Astro），我没有传统的服务器和数据库。但我需要存储一些动态内容：</p><ol>
<li><strong>说说</strong>（类似朋友圈/微博）— 随时发布短文和图片</li>
<li><strong>笔记</strong>（类似日记本）— 记录每日所思所想</li>
</ol><p>这些内容需要频繁更新，但我不希望每次都修改代码仓库、重新部署。</p><p>对比了几种方案：</p>

<table><thead><tr><th>方案</th><th>成本</th><th>复杂度</th><th>适合场景</th></tr></thead><tbody><tr><td>自建数据库</td><td>服务器费用</td><td>高</td><td>大型项目</td></tr><tr><td>Supabase/Firebase</td><td>免费 tier 有限</td><td>中</td><td>需要实时数据库</td></tr><tr><td>Cloudflare KV</td><td>免费 tier 够用</td><td>中</td><td>需要边缘存储</td></tr><tr><td><strong>GitHub Gist</strong></td><td><strong>完全免费</strong></td><td><strong>低</strong></td><td><strong>小规模结构化数据</strong></td></tr></tbody></table><p>最终选择了 Gist，因为：</p><ul>
<li>完全免费，无任何限制</li>
<li>与 GitHub 生态无缝集成</li>
<li>支持版本历史，天然备份</li>
<li>API 简单易用</li>
<li>无需注册新服务</li>
</ul></section>

<section><h2 id="注意事项">注意事项</h2><ol>
<li><strong>Gist 默认公开</strong>：创建时选 Secret Gist，但知道 URL 的人仍可访问</li>
<li><strong>单文件大小限制</strong>：建议 1MB 以内</li>
<li><strong>API 频率限制</strong>：5000 次/小时，个人博客完全够用</li>
<li><strong>图片不存 Gist</strong>：图片使用外部 CDN，Gist 只存 Markdown 文本和图片 URL</li>
<li><strong>备份</strong>：Gist 本质是 Git 仓库，有完整版本历史</li>
</ol></section>
<section><h2 id="总结">总结</h2><p>GitHub Gist 作为一个免费、可靠的轻量级存储服务，非常适合作为静态博客的动态内容存储。通过使用 Raw URL 读取数据，我们实现了：</p><ul>
<li>零服务器成本</li>
<li>零额外依赖</li>
<li>简单的数据读取</li>
<li>完整的版本历史</li>
</ul><p>如果你也有一个静态博客，想要存储一些动态内容，不妨试试这个方案。</p></section>
