<li><strong>点击事件</strong>：按钮点击、提交操作</li>
<li><strong>表单处理</strong>：表单提交、输入验证</li>
<li><strong>元素交互</strong>：鼠标悬停、移出效果</li>
<li><strong>键盘事件</strong>：快捷键、输入监听</li>
<li><strong>数据操作</strong>：增删改查功能触发</li>
</ol></section><section><h2 id="注意事项">注意事项</h2><ol>
<li>
<p><strong>事件处理方法</strong>：</p>
<ul>
<li>必须在Vue实例的<code>methods</code>中定义</li>
<li>方法名使用驼峰命名（camelCase）</li>
<li>方法中通过<code>this</code>访问Vue实例数据</li>
</ul>
</li>
<li>
<p><strong>this指向</strong>：</p>
<ul>
<li><code>methods</code>函数中的<code>this</code>指向Vue实例</li>
<li>可以通过<code>this</code>获取到<code>data()</code>中定义的数据</li>
</ul>
</li>
<li>
<p><strong>事件修饰符</strong>：</p>
<ul>
<li><code>.prevent</code>：阻止默认行为</li>
<li><code>.stop</code>：阻止事件冒泡</li>
<li><code>.once</code>：事件只触发一次</li>
</ul>
</li>
<li>
<p><strong>与原生JS事件区别</strong>：</p>
<ul>
<li>不需要手动获取DOM元素</li>
<li>方法直接绑定，更简洁</li>
<li>数据更新自动反映到视图</li>
</ul>
</li>
<li>
<p><strong>常见事件类型</strong>：</p>
<ul>
<li>click：鼠标点击</li>
<li>submit：表单提交</li>
<li>keyup/keydown：键盘事件</li>
<li>input：输入变化</li>
</ul>
</li>
</ol></section></section>
