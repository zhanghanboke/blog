<table><thead><tr><th>方式</th><th>优点</th><th>缺点</th><th>使用情况</th></tr></thead><tbody><tr><td>行内样式</td><td>直接、优先级最高</td><td>代码冗余、维护困难</td><td>不常用（偶尔配合 JS）</td></tr><tr><td>内部样式</td><td>当前页面集中管理</td><td>无法跨页面复用</td><td>小型页面、演示示例</td></tr><tr><td>外部样式</td><td>HTML/CSS 完全分离、可复用</td><td>额外 HTTP 请求</td><td><strong>企业开发常用方式</strong></td></tr></tbody></table></section><section><h4 id="常见场景">常见场景</h4><ul>
<li><strong>外部样式</strong>：项目中所有页面的统一样式管理</li>
<li><strong>内部样式</strong>：单页面独立样式、快速原型</li>
<li><strong>行内样式</strong>：通过 JavaScript 动态设置的样式</li>
</ul></section><section><h4 id="注意事项">注意事项</h4><ul>
<li>三种方式中，行内样式优先级最高（权重：行内 > 内部/外部，后者按选择器优先级和声明顺序决定）</li>
<li>外部样式文件通常创建在 <code>css/</code> 目录下</li>
<li>企业开发中外部样式是标准做法，实现结构（HTML）与表现（CSS）的完全分离</li>
</ul><hr></section></section>
