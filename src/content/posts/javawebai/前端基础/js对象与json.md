<li><strong>自定义对象</strong>：封装实体数据，如用户信息、商品信息等</li>
<li><strong>JSON.stringify()</strong>：将JS对象转换为JSON字符串，用于发送数据到服务器</li>
<li><strong>JSON.parse()</strong>：将JSON字符串转换为JS对象，用于解析服务器返回的数据</li>
<li><strong>前端与后端通信</strong>：API调用中JSON是主要的数据传输格式</li>
</ol></section><section><h2 id="注意事项">注意事项</h2><ol>
<li><strong>JSON的key必须使用双引号</strong>，单引号或省略引号不符合JSON规范</li>
<li><strong>JSON不支持函数</strong>，只能表示数据</li>
<li><strong>对象方法简化语法</strong>：<code>sing() { ... }</code> 等同于 <code>sing: function() { ... }</code></li>
<li><strong>JSON.stringify循环引用问题</strong>：如果对象包含循环引用，<code>JSON.stringify()</code>会抛出错误</li>
<li><strong>深度比较</strong>：两个内容相同的JS对象不相等，只有引用相同的才相等</li>
</ol></section></section>
