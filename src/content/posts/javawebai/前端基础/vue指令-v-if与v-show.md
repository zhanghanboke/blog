id="常见场景">常见场景</h2><ol>
<li>
<p><strong>v-if适用场景</strong>：</p>
<ul>
<li>条件不经常变化</li>
<li>初始渲染条件为false时不需要渲染</li>
<li>需要配合v-else或v-else-if使用</li>
<li>性能要求不高，但需要完全销毁/重建元素</li>
</ul>
</li>
<li>
<p><strong>v-show适用场景</strong>：</p>
<ul>
<li>条件频繁切换</li>
<li>初始渲染成本较高</li>
<li>只需要简单的显示/隐藏切换</li>
<li>需要保持元素状态（如表单输入）</li>
</ul>
</li>
</ol></section><section><h2 id="注意事项">注意事项</h2><ol>
<li>
<p><strong>实现机制差异</strong>：</p>
<ul>
<li><code>v-if</code>：条件为false时，元素从DOM中移除</li>
<li><code>v-show</code>：条件为false时，元素通过<code>display: none</code>隐藏</li>
</ul>
</li>
<li>
<p><strong>性能考虑</strong>：</p>
<ul>
<li><code>v-if</code>有更高的切换开销（创建/销毁）</li>
<li><code>v-show</code>有更高的初始渲染开销（总是渲染）</li>
<li>频繁切换用<code>v-show</code>，运行时条件很少改变用<code>v-if</code></li>
</ul>
</li>
<li>
<p><strong>v-else规则</strong>：</p>
<ul>
<li><code>v-else</code>必须紧跟在<code>v-if</code>或<code>v-else-if</code>之后</li>
<li><code>v-else-if</code>必须出现在<code>v-if</code>之后</li>
<li>可以有多个<code>v-else-if</code></li>
</ul>
</li>
<li>
<p><strong>与v-for一起使用</strong>：</p>
<ul>
<li>不推荐在同一元素上同时使用<code>v-if</code>和<code>v-for</code></li>
<li>需要时，<code>v-if</code>的优先级更高</li>
</ul>
</li>
</ol></section><section><h2 id="相关链接">相关链接</h2><ul>
