<section><h1 id="部门新增功能">部门新增功能</h1><section><h2 id="定义">定义</h2><p>部门新增功能用于保存新的部门数据。前端以 JSON 格式传递部门名称，后端通过 <code>@RequestBody</code> 注解将 JSON 数据绑定到实体对象，完成数据持久化。</p></section><section><h2 id="接口描述">接口描述</h2><ul>
<li>请求方式：POST</li>
<li>请求路径：<code>/depts</code></li>
<li>请求参数：JSON 格式 <code>{"name":"研发部"}</code></li>
<li>响应数据：<code>Result</code>（统一响应结果）</li>
</ul></section><section><h2 id="实现思路">实现思路</h2><p></p><center><figure><img src="/media/6a29843dc197.png" alt=""><figcaption>新增部门三层架构</figcaption></figure></center><p></p><ul>
<li><strong>Controller 层</strong>：接收前端 JSON 请求参数，调用 Service 保存部门</li>
<li><strong>Service 层</strong>：补全基础属性（创建时间、修改时间），调用 Mapper 保存</li>
<li><strong>Mapper 层</strong>：执行 INSERT SQL 语句</li>
</ul></section><section><h2 id="json-参数接收">JSON 参数接收</h2><p>前端传递 JSON 格式参数时，使用实体对象接收。</p><p>规则：<strong>JSON 数据的键名与方法形参对象的属性名相同，并使用 <code>@RequestBody</code> 注解标识。</strong></p><p></p><center><figure><img src="/media/b6de3731fd04.png" alt=""><figcaption>JSON参数接收</figcaption></figure></center><p></p><p>如上图，JSON <code>{"name":"研发部"}</code> 通过 <li>表单提交新增记录，前端发送 JSON 请求体</li>
<li>批量导入时循环调用新增接口</li>
</ul></section><section><h2 id="注意事项">注意事项</h2><ul>
<li><code>@RequestBody</code> 注解必须加在 Controller 方法形参前，否则无法绑定 JSON</li>
<li>JSON 的 key 必须与实体类属性名一致</li>
<li><code>#{...}</code> 中应填写 Java 对象的属性名（驼峰命名），而非数据库字段名</li>
<li>Service 层负责补全非业务字段（如时间戳），保持 Controller 层简洁</li>
