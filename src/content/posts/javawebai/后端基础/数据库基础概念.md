<section><h1 id="数据库基础概念">数据库基础概念</h1><section><h2 id="定义">定义</h2><ul>
<li><strong>数据库（DataBase，简称DB）</strong>：存储和管理数据的仓库。</li>
<li><strong>数据库管理系统（DataBase Management System，简称DBMS）</strong>：操作和管理数据库的大型软件。</li>
<li><strong>SQL（Structured Query Language）</strong>：结构化查询语言，操作关系型数据库的编程语言，定义了操作所有关系型数据库的统一标准。</li>
</ul><p>三者关系：程序员给 DBMS 发送 SQL 语句，再由 DBMS 操作数据库中的数据。</p><p></p><center><figure><img src="/media/e774c2bb682c.png" alt=""><figcaption>数据库概念关系</figcaption></figure></center><p></p></section><section><h2 id="web开发中的数据流">Web开发中的数据流</h2><p>在 SpringBoot Web 开发中，程序分层为 Controller → Service → Dao。真实企业开发中，Dao 层不再读写文本文件，而是通过 SQL 操作数据库：</p><p></p><center><figure><img src="/media/c3a94f556af9.png" alt=""><figcaption>Web开发调用流程</figcaption></figure></center><p></p></section><section><h2 id="主流数据库排名">主流数据库排名</h2>

<li>MySQL 目前由 Oracle 维护，分为社区版（免费）和企业版（收费）。</li>
<li>所有关系型数据库都遵循统一的 SQL 标准，学会 SQL 即可操作 MySQL、Oracle、SQL Server 等。</li>
<li>课程大纲：MySQL 概述 → SQL（DDL/DML/DQL）→ 多表设计 → 多表查询 → 事务 → 索引。</li>
