<section><h1 id="部门查询功能">部门查询功能</h1><section><h2 id="定义">定义</h2><p>部门查询功能用于查询所有部门数据并展示在部门管理页面中。基于 SpringBoot 三层架构（Controller → Service → Mapper）实现，涉及 MyBatis 字段映射、驼峰命名规则、请求方式限定以及前后端联调。</p></section><section><h2 id="实现思路">实现思路</h2><p>三层架构每一层的职责：</p><p></p><center><figure><img src="/media/6d0d25936e5e.png" alt=""><figcaption>查询部门三层架构</figcaption></figure></center><p></p><ul>
<li><strong>Controller 层</strong>：接收前端请求，调用 Service 查询部门数据，响应结果</li>
<li><strong>Service 层</strong>：调用 Mapper 接口方法，查询所有部门数据</li>
<li><strong>Mapper 层</strong>：执行查询所有部门数据的 SQL 操作</li>

服务器。</p><p></p><center><figure><img src="/media/0cb00fa1e6d9.png" alt=""><figcaption>Nginx反向代理</figcaption></figure></center><p></p><p>请求访问流程：</p><p></p><center><figure><img src="/media/17d2db2e88bf.png" alt=""><figcaption>请求访问流程</figcaption></figure></center><p></p><p>Nginx 配置关键指令：</p><ul>
<li><code>location</code>：定义匹配特定 URI 请求的规则</li>
<li><code>^~ /api/</code>：精确匹配以 <code>/api/</code> 开头的路径</li>
<li><code>rewrite</code>：重写匹配到的 URI 路径</li>
<li><code>proxy_pass</code>：代理转发，将匹配到的请求转发给后端服务器</li>
</ul><p>使用 Nginx 反向代理的原因：</p><ol>
<li><strong>安全</strong>：后端 Tomcat 集群不直接暴露给前端</li>
<li><strong>灵活</strong>：后端增减服务器对前端无感知，只需修改 Nginx 配置</li>
<li><strong>负载均衡</strong>：可方便实现后端 Tomcat 的负载均衡</li>
</ol></section><section><h2 id="常见场景">常见场景</h2><ul>

<li>数据库下划线字段与 Java 驼峰属性之间的自动映射</li>
</ul></section><section><h2 id="注意事项">注意事项</h2><ul>
