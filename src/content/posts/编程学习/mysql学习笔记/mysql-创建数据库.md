<section><h2 id="使用-mysqladmin-创建数据库">使用 mysqladmin 创建数据库</h2><p>mysqladmin 是 MySQL 提供的一个用于执行管理任务的命令行工具。</p><p>通过 mysqladmin，你可以执行各种数据库管理操作，包括创建数据库。</p><p>以下是使用 mysqladmin 创建数据库的基本语法：</p><div class="expressive-code"><figure class="frame"><figcaption class="header"></figcaption><pre data-language="mysql"><code><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">1</div></div><div class="code"><span style="--0:#abb2bf;--1:#383a42">mysqladmin -u your_username -p create your_database</span></div></div></code></pre><div class="copy"><div aria-live="polite"></div><button title="Copy to clipboard" data-copied="Copied!" data-code="mysqladmin -u your_username -p create your_database"><div></div></button></div></figure></div><ul>
<li><code>-u</code> 参数用于指定 MySQL 用户名。</li>
<li><code>-p</code> 参数表示需要输入密码。</li>
<li><code>create</code> 是执行的操作，表示创建数据库。</li>
<li><code>your_database</code> 是要创建的数据库的名称。</li>
</ul><p>使用普通用户，你可能需要特定的权限来创建或者删除 MySQL 数据库。</p><p>我们这边使用 root 用户登录，root 用户拥有最高权限，可以使用 mysql mysqladmin 命令来创建数据库。</p><p>执行上述命令后，系统会提示你输入密码，输入密码后按 Enter 键即可。</p><p>以下命令简单的演示了创建数据库的过程，数据名为
