<p>使用普通用户登陆 MySQL 服务器，你可能需要特定的权限来创建或者删除 MySQL 数据库，所以我们这边使用 root 用户登录，root 用户拥有最高权限。</p>
<p>在删除数据库过程中，务必要十分谨慎，因为在执行删除命令后，所有数据将会消失。</p>
<section><h2 id="drop-命令删除数据库">drop 命令删除数据库</h2><p>drop 命令格式：</p><div class="expressive-code"><figure class="frame"><figcaption class="header"></figcaption><pre data-language="mysql"><code><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">1</div></div><div class="code"><span style="--0:#abb2bf;--1:#383a42">DROP DATABASE &#x3C;database_name>;        -- 直接删除数据库，不检查是否存在</span></div></div><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">2</div></div><div class="code"><span style="--0:#abb2bf;--1:#383a42">或</span></div></div><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">3</div></div><div class="code"><span style="--0:#abb2bf;--1:#383a42">DROP DATABASE [IF EXISTS] &#x3C;database_name>;</span></div></div></code></pre><div class="copy"><div aria-live="polite"></div><button title="Copy to clipboard" data-copied="Copied!" data-code="DROP DATABASE <database_name>;        -- 直接删除数据库，不检查是否存在或DROP DATABASE [IF EXISTS] <database_name>;"><div></div></button></div></figure></div><p><strong>参数说明：</strong></p><ul>
<li><code>IF EXISTS</code> 是一个可选的子句，表示如果数据库存在才执行删除操作，避免因为数据库不存在而引发错误。</li>
<li><code>database_name</code> 是你要删除的数据库的名称。</li>
</ul><p>例如删除名为 RUNOOB 的数据库：</p><div class="expressive-code"><figure class="frame"><figcaption class="header"></figcaption><pre data-language="mysql"><code><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">1</div></div><div class="code"><span style="--0:#abb2bf;--1:#383a42">-- 直接删除数据库，不检查是否存在</span></div></div><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">2</div></div><div class="code"><span style="--0:#abb2bf;--1:#383a42">mysql> DROP DATABASE RUNOOB;</span></div></div><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">3</div></div><div class="code">
</div></div><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">4</div></div><div class="code"><span style="--0:#abb2bf;--1:#383a42">-- 删除数据库，如果存在的话</span></div></div><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">5</div></div><div class="code"><span style="--0:#abb2bf;--1:#383a42">DROP DATABASE IF EXISTS RUNOOB;</span></div></div></code></pre><div class="copy"><div aria-live="polite"></div><button title="Copy to clipboard" data-copied="Copied!" data-code="-- 直接删除数据库，不检查是否存在mysql> DROP DATABASE RUNOOB;-- 删除数据库，如果存在的话DROP DATABASE IF EXISTS RUNOOB;"><div></div></button></div></figure></div><p><strong>注意：</strong> 在执行删除数据库操作前，请确保你确实想要删除数据库及其所有数据，因为该操作是不可逆的。为了避免误操作，通常建议在执行删除之前备份数据库。</p></section>
