DBeaver</h3><p>DBeaver是一款免费、开源、跨平台的数据库管理工具。</p><p>DBeaver 支持多种数据库系统，包括 MySQL、PostgreSQL、MariaDB、SQLite、Oracle、DB2、SQL Server、Sybase、MS Access、Teradata、Firebird、Derby 等。</p><p>下载地址： <a href="https://dbeaver.io/download/" target="_blank" rel="noopener noreferrer">https://dbeaver.io/download/</a></p><p><img src="/media/20f45dc303c2.webp" alt=""></p></section><section><h3 id="2-dbgate">2. DbGate</h3><p>DbGate 是一款跨平台的数据库管理工具，支持多种数据库系统，包括 MySQL、PostgreSQL、Microsoft SQL Server、SQLite、MongoDB 等。</p><p>DbGate 支持在 Windows、Linux 和 Mac 操作系统上运行，为用户提供了跨平台的灵活性。</p><p>DbGate 不仅仅是本地应用程序，还可以作为 Web 应用程序运行，使用户能够通过浏览器轻松访问和管理数据库。</p><p>下载地址： <a href="https://dbgate.org/download/" target="_blank" rel="noopener noreferrer">https://dbgate.org/download/</a></p><p><img src="/media/ee948520d557.webp" alt=""></p><hr></section></section>
<section><h2 id="操作练习">操作练习</h2><ul class="contains-task-list">
<li class="task-list-item"><input type="checkbox" checked disabled> 练习 1：使用命令行连接 MySQL</li>
</ul><ol>
<li>打开 Windows 的命令提示符（按 <code>Win + R</code>，输入 <code>cmd</code>，然后回车）。</li>
<li>在命令提示符中，输入以下命令并回车：
<div class="expressive-code"><figure class="frame is-terminal"><figcaption class="header"><span class="title"></span><span class="sr-only">Terminal window</span></figcaption><pre data-language="bash"><code><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">1</div></div><div class="code"><span style="--0:#61AFEF;--1:#3360C1">mysql</span><span style="--0:#ABB2BF;--1:#383A42"> </span><span style="--0:#D19A66;--1:#875D01">-u</span><span style="--0:#ABB2BF;--1:#383A42"> </span><span style="--0:#98C379;--1:#387138">root</span><span style="--0:#ABB2BF;--1:#383A42"> </span><span style="--0:#D19A66;--1:#875D01">-p</span></div></div></code></pre><div class="copy"><div aria-live="polite"></div><button title="Copy to clipboard" data-copied="Copied!" data-code="mysql -u root -p"><div></div></button></div></figure></div>
</li>
<li>系统会提示你输入密码。输入你的 MySQL root 用户密码（密码输入时不会显示字符，这是正常的），然后按回车。</li>
<li>如果看到 <code>mysql></code> 提示符，说明连接成功。</li>
<li>在 <code>mysql></code> 提示符下，输入 <code>exit;</code> 或 <code>quit;</code> 退出连接。</li>
</ol><ul class="contains-task-list">
<li class="task-list-item"><input type="checkbox" checked disabled> 练习 2：使用图形化工具 DBeaver 连接 MySQL</li>
</ul><ol>
<li>从官网 <a href="https://dbeaver.io/download/" target="_blank" rel="noopener noreferrer">https://dbeaver.io/download/</a> 下载并安装 DBeaver（Windows 版）。</li>
<li>启动 DBeaver。</li>
<li>点击左上角的“新建数据库连接”按钮（插头形状的图标），或点击菜单栏的“数据库” -> “新建数据库连接”。</li>
<li>在弹出的窗口中，选择“MySQL”，然后点击“下一步”。</li>
<li>在“连接设置”窗口中，填写以下信息：
<ul>
<li><strong>服务器主机</strong>：<code>localhost</code> 或 <code>127.0.0.1</code>（如果 MySQL 在本机）。</li>
<li><strong>端口</strong>：<code>3306</code>（MySQL 默认端口）。</li>
<li><strong>数据库</strong>：可以留空，或输入一个已存在的数据库名（如 <code>test</code>）。</li>
<li><strong>用户名</strong>：<code>root</code>（或你的 MySQL 用户名）。</li>
<li><strong>密码</strong>：输入你的 MySQL 密码。</li>
</ul>
</li>
<li>点击“测试连接”按钮。如果提示“已连接”，说明设置正确。</li>
<li>点击“完成”保存连接。现在你可以在左侧的“数据库导航”中看到你的 MySQL 服务器，并像操作文件夹一样浏览数据库和表。</li>
</ol><ul class="contains-task-list">
