<section><h2 id="一-集合概述">一、 集合概述</h2><section><h3 id="11-集合的好处-相比数组">1.1 集合的好处 (相比数组)</h3><ul>
<li><strong>动态保存</strong>：可以保存任意多个对象，长度可变。</li>
<li><strong>丰富API</strong>：提供了一系列方便操作对象的方法，如 add, remove, set, get 等。</li>
<li><strong>代码简洁</strong>：使用集合进行增删改查比数组更简洁。</li>
</ul></section><section><h3 id="12-集合框架体系-两大主线">1.2 集合框架体系 (两大主线)</h3><p>Java集合主要分为两大类：<strong>单列集合</strong> (Collection) 和 <strong>双列集合</strong> (Map)。</p><ul>
<li><strong>Collection</strong> <strong>接口</strong>：存放单个对象。
<ul>
<li>有两个重要子接口：List 和 Set。</li>
<li>List：有序、可重复。
<ul>
<li>主要实现类：ArrayList, LinkedList, Vector。</li>
</ul>
</li>
<li>Set：无序、不可重复。
<ul>
<li>主要实现类：HashSet, LinkedHashSet, TreeSet。</li>
</ul>
</li>
</ul>
</li>
<li><strong>Map</strong> <strong>接口</strong>：存放键值对 K-V。
<ul>
<li>主要实现类：HashMap, Hashtable, TreeMap, LinkedHashMap, Properties。</li>
</ul>
</li>
</ul></section></section>
<section><h2 id="二-collection-接口">二、 Collection 接口</h2><section><h3 id="21-collection-接口特点">2.1 Collection 接口特点</h3><ol>
<li>可以存放多个元素，每个元素是 Object。</li>
<li>有些实现类可存放重复元素 (List)，有些不可以 (Set)。</li>
<li>有些是有序的 (List)，有些不是 (Set)。</li>
<li>Collection 接口没有直接实现类，通过其子接口 Set 和 List 实现。</li>
</ol></section><section><h3 id="22-collection-接口遍历元素方式">2.2 Collection 接口遍历元素方式</h3><ol>
<li><strong>使用 Iterator 迭代器</strong>
<ul>
<li>所有实现了 Collection 接口的集合都有一个 iterator() 方法，返回迭代器对象。</li>
</ul>
</li>
</ol><p><img alt="" loading="lazy" decoding="async" width="638" height="268" src="/media/3f1609fcd1e3.webp" srcset=""></p><ul>
<li>迭代器仅用于遍历，本身不存放对象。</li>
<li><strong>执行原理</strong>：hasNext() 判断是否还有下一个元素，next() 下移并返回元素。</li>
</ul><p><img alt="" loading="lazy" decoding="async" width="685" height="400" src="/media/338fc5ec8a31.webp" srcset=""></p><ul>
<li><strong>注意</strong>：在调用 next() 之前必须调用 hasNext() 检测，否则可能抛出 NoSuchElementException。</li>
</ul><ol start="6">
<li><strong>增强 for 循环</strong>
<ul>
<li>本质就是迭代器的简化版，语法更简洁。</li>
<li>只能用于遍历集合或数组。</li>
<li>语法：for(元素类型 元素名 : 集合名或数组名) { //访问元素 }</li>
</ul>
</li>
</ol></section></section>
<section><h2 id="三-list-接口">三、 List 接口</h2><section><h3 id="31-list-接口特点">3.1 List 接口特点</h3><ol>
<li><strong>有序</strong>：添加顺序和取出顺序一致。</li>
<li><strong>可重复</strong>：允许存放相同的元素。</li>
<li><strong>支持索引</strong>：每个元素都有其对应的顺序索引 (0-based)，可以通过 get(int index) 方法获取。</li>
</ol></section><section><h3 id="32-list-接口常用方法">3.2 List 接口常用方法</h3><ul>
<li>add(int index, Object ele)：在 index 位置插入 ele 元素。</li>
<li>addAll(int index, Collection eles)：从 index 位置开始将 eles 中的所有元素添加进来。</li>
<li>get(int index)：获取指定 index 位置的元素。</li>
<li>indexOf(Object obj)：返回 obj 在集合中首次出现的位置。</li>
<li>lastIndexOf(Object obj)：返回 obj 在集合中末次出现的位置。</li>
<li>remove(int index)：移除指定 index 位置的元素，并返回此元素。</li>
<li>set(int index, Object ele)：设置指定 index 位置的元素为 ele，相当于替换。</li>
<li>subList(int fromIndex, int toIndex)：返回从 fromIndex 到 toIndex 位置的子集合（前闭后开）。</li>
</ul></section><section><h3 id="33-list-的三种遍历方式">3.3 List 的三种遍历方式</h3><ol>
<li>迭代器 Iterator</li>
<li>增强 for 循环</li>
<li>普通 for 循环（利用索引）</li>
</ol></section></section>
<section><h2 id="四-list-接口实现类">四、 List 接口实现类</h2><section><h3 id="41-arraylist">4.1 ArrayList</h3><ul>
<li><strong>底层结构</strong>：可变长度的对象数组 Object[] elementData。</li>
<li><strong>线程安全</strong>：<strong>线程不安全</strong>，但执行效率高。</li>
<li><strong>扩容机制</strong>：
<ul>
<li><strong>无参构造器</strong>：初始容量为0，第一次添加扩容至10，后续需要扩容时，按当前容量的1.5倍扩容。</li>
<li><strong>有参构造器</strong>：初始容量为指定大小，后续需要扩容时，同样按1.5倍扩容。</li>
</ul>
</li>
<li><strong>其他</strong>：可以加入 null，且允许多个。</li>
</ul></section><section><h3 id="42-vector">4.2 Vector</h3><ul>
<li>
<p><strong>底层结构</strong>：对象数组 Object[] elementData。
<img alt="" loading="lazy" decoding="async" width="783" height="293" src="/media/ec531bbe84a4.webp" srcset=""></p>
</li>
<li>
<p><strong>线程安全</strong>：<strong>线程安全</strong>（方法带有 synchronized 关键字），但效率较低。</p>
</li>
<li>
<p><strong>扩容机制</strong>：</p>
<ul>
<li><strong>无参构造器</strong>：默认初始容量10，满后按2倍扩容。</li>
<li><strong>有参构造器</strong>：初始容量为指定大小，满后按2倍扩容。</li>
</ul>
</li>
<li>
<p><strong>与 ArrayList 比较</strong></p>
</li>
</ul>

<li><strong>底层结构</strong>：<strong>双向链表</strong>。维护了属性 first 和 last 分别指向首尾节点。每个节点 (Node) 有 prev, item, next 属性。</li>
<li><strong>特点</strong>：实现了双向链表和双端队列接口。可以添加任意元素（包括 null）。线程不安全。</li>
<li><strong>操作机制</strong>：元素的添加和删除通过操作链表完成，不涉及数组扩容，因此<strong>增删效率高，改查效率低</strong>。</li>
<li><strong>与 ArrayList 比较</strong></li>
</ul>

<section><h2 id="五-set-接口">五、 Set 接口</h2><section><h3 id="51-set-接口特点">5.1 Set 接口特点</h3><ol>
<li><strong>无序</strong>（添加和取出顺序不一致，但 LinkedHashSet 和 TreeSet 除外）。</li>
<li><strong>不允许重复元素</strong>，最多包含一个 null。</li>
<li><strong>没有索引</strong>，不能使用普通 for 循环遍历。</li>
<li><strong>遍历方式</strong>：迭代器、增强 for 循环。</li>
</ol></section><section><h3 id="52-hashset">5.2 HashSet</h3><ul>
<li><strong>底层结构</strong>：<strong>HashMap</strong>。即底层是 数组 + 链表 + 红黑树。</li>
<li><strong>添加机制</strong>（去重核心）：
<ol>
<li>添加元素时，先得到 hash 值，然后转成索引值。</li>
<li>找到存储数据表 table，看索引位置是否已有元素。</li>
<li>如果没有，直接加入。</li>
<li>如果有，调用 equals 比较：
<ul>
<li>如果相同，放弃添加。</li>
<li>如果不同，则添加到链表的最后（或树化）。</li>
</ul>
</li>
</ol>
</li>
</ul><ol start="30">
<li><strong>扩容与树化</strong>：
<ul>
<li>第一次添加时，table 扩容到16，临界值 (threshold) 为 16 * 0.75 = 12。</li>
<li>如果 table 使用到临界值，就扩容到 当前容量 * 2，临界值也相应更新。</li>
<li><strong>树化</strong>：当一条链表的元素个数达到 TREEIFY_THRESHOLD (默认8)，并且 table 的大小 >= MIN_TREEIFY_CAPACITY (默认64)，该链表会转为红黑树，否则仍采用数组扩容。</li>
</ul>
</li>
</ol></section><section><h3 id="53-linkedhashset">5.3 LinkedHashSet</h3><ul>
<li><strong>底层结构</strong>：<strong>LinkedHashMap</strong>。是 HashSet 的子类。</li>
<li><strong>特点</strong>：在 HashSet 数组+链表/红黑树的基础上，增加了一套<strong>双向链表</strong>，用于维护元素的添加顺序。这使得元素看起来是以插入顺序保存的。</li>
<li><strong>优点</strong>：既拥有了 HashSet 的去重能力，又能保证遍历顺序与插入顺序一致。</li>
</ul></section><section><h3 id="54-treeset">5.4 TreeSet</h3><ul>
<li><strong>底层结构</strong>：<strong>TreeMap</strong>（红黑树）。</li>
<li><strong>排序/去重机制</strong>：
<ol>
<li><strong>传入比较器 (<strong><strong>Comparator</strong></strong>)</strong>：使用构造器传入的 Comparator 对象的 compare 方法进行排序和去重。返回0则认为相同，不添加。</li>
<li><strong>未传入比较器</strong>：则使用添加对象实现的 Comparable 接口的 compareTo 方法去重。如果对象没有实现 Comparable，添加时会抛出 ClassCastException。</li>
</ol>
</li>
</ul></section></section>
<section><h2 id="六-map-接口">六、 Map 接口</h2><section><h3 id="61-map-接口特点">6.1 Map 接口特点</h3><ol>
<li>Map 与 Collection 并列存在，用于保存具有<strong>映射关系</strong>的数据 Key-Value。</li>
<li>Key 和 Value 可以是任何引用类型数据，封装在 HashMap$Node 对象中。</li>
<li>Key <strong>不允许重复</strong>（原因同 HashSet），Value 可以重复。</li>
<li>Key 可以为 null（仅一个），Value 可以为 null（多个）。</li>
<li>常用 String 类作为 Map 的 Key。</li>
<li>Key 和 Value 是单向一对一关系，通过指定的 Key 总能找到对应的 Value。</li>
</ol></section><section><h3 id="62-map-接口遍历方式">6.2 Map 接口遍历方式</h3><ol>
<li><strong>keySet()</strong>：获取所有 Key 的 Set 集合，然后通过 get(key) 获取 Value。</li>
<li><strong>values()</strong>：获取所有 Value 的 Collection 集合。</li>
<li><strong>entrySet()</strong>：获取所有 Entry (K-V 对) 的 Set 集合。然后可以从 Entry 对象中获取 getKey() 和 getValue()。</li>
</ol></section><section><h3 id="63-hashmap">6.3 HashMap</h3><ul>
<li><strong>使用频率最高的</strong> <strong>Map</strong> <strong>实现类</strong>。</li>
<li><strong>线程不安全</strong>，方法未同步。</li>
<li><strong>底层机制</strong>：数组 + 链表 + 红黑树。</li>
<li><strong>扩容机制</strong>：与 HashSet 完全相同（因为 HashSet 底层就是 HashMap）。
<ul>
<li>首次扩容到16，临界值12。</li>
<li>后续扩容为2倍，临界值 = 新容量 * 0.75。</li>
<li>树化条件：链表长度 >= 8 且 数组长度 >= 64。</li>
</ul>
</li>
<li><strong>添加/替换机制</strong>：添加相同的 Key 会覆盖原来的 Value，等同于修改。</li>
</ul></section><section><h3 id="64-hashtable">6.4 Hashtable</h3><ul>
<li><strong>线程安全</strong>的 Map 实现类（方法使用 synchronized 修饰），效率较低。</li>
<li><strong>键和值都不能为</strong> <strong>null</strong>，否则抛出 NullPointerException。</li>
<li><strong>与 HashMap 比较</strong>：</li>
</ul>

<li>继承自 Hashtable 并实现了 Map 接口。</li>
<li>同样使用 K-V 结构，<strong>键和值也不能为</strong> <strong>null</strong>。</li>
<li>通常用于从 .properties 配置文件中加载数据，在IO流中常用。</li>
</ul></section></section>
<section><h2 id="七-collections-工具类">七、 Collections 工具类</h2><section><h3 id="71-介绍">7.1 介绍</h3><p>Collections 是一个操作 Set、List 和 Map 等集合的<strong>工具类</strong>，提供了一系列静态方法。</p></section><section><h3 id="72-常用方法">7.2 常用方法</h3><ul>
<li><strong>排序操作</strong>：
<ul>
<li>reverse(List)：反转顺序。</li>
<li>shuffle(List)：随机排序。</li>
<li>sort(List)：自然排序（升序）。</li>
<li>sort(List, Comparator)：定制排序。</li>
<li>swap(List, int, int)：交换元素。</li>
</ul>
</li>
<li><strong>查找、替换</strong>：
<ul>
<li>max(Collection) / min(Collection)：返回最大/最小元素。</li>
<li>max(Collection, Comparator) / min(Collection, Comparator)：定制比较返回最大/最小。</li>
<li>frequency(Collection, Object)：返回指定元素出现次数。</li>
<li>copy(List dest, List src)：将 src 内容复制到 dest。</li>
<li>replaceAll(List list, Object oldVal, Object newVal)：使用新值替换所有旧值。</li>
</ul>
</li>
</ul></section></section>
<section><h2 id="八-开发中选择集合实现类的建议">八、 开发中选择集合实现类的建议</h2><ul>
<li><strong>单列情况</strong>：
<ul>
<li>需要<strong>唯一元素</strong> -> Set
<ul>
<li>需要<strong>顺序</strong> -> TreeSet (排序) 或 LinkedHashSet (插入顺序)。</li>
<li>不需要顺序 -> HashSet。</li>
</ul>
</li>
<li>允许<strong>重复元素</strong> -> List
<ul>
<li>增删多 -> LinkedList。</li>
<li>查改多 -> ArrayList。</li>
</ul>
</li>
<li>不确定情况 -> ArrayList。</li>
</ul>
</li>
<li><strong>双列情况 (键值对)</strong>：
<ul>
<li>-> Map
<ul>
<li>需要排序 -> TreeMap。</li>
<li>不需要排序，但需要保持插入或访问顺序 -> LinkedHashMap。</li>
<li>其他情况 -> HashMap。</li>
</ul>
</li>
</ul>
</li>
<li><strong>线程安全</strong>：
<ul>
<li>需要线程安全 -> 使用 Collections.synchronizedXXX() 包装，或考虑 ConcurrentHashMap (对于 Map)。</li>
</ul>
</li>
</ul></section>
