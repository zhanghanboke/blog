<section><h2 id="一动态代理核心概念">一、动态代理核心概念</h2><section><h3 id="11-什么是代理模式">1.1 什么是代理模式？</h3><div class="expressive-code"><figure class="frame"><figcaption class="header"></figcaption><pre data-language="plaintext"><code><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">1</div></div><div class="code"><span style="--0:#abb2bf;--1:#383a42">代理模式 = 代理对象 + 目标对象</span></div></div></code></pre><div class="copy"><div aria-live="polite"></div><button title="Copy to clipboard" data-copied="Copied!" data-code="代理模式 = 代理对象 + 目标对象"><div></div></button></div></figure></div><ul>
<li><strong>代理对象</strong>：不直接实现服务，而是通过调用目标对象的方法来提供服务</li>
<li><strong>目标对象</strong>：真正执行业务逻辑的对象</li>
<li><strong>核心价值</strong>：在不修改目标对象代码的前提下，增强或控制目标对象的行为</li>
</ul></section><section><h3 id="12-静态代理-vs-动态代理">1.2 静态代理 vs 动态代理</h3>
