<section><h2 id="一面向对象与类对象概述">一、面向对象与类、对象概述</h2><ul>
<li>​<strong>核心思想</strong>​：​<strong>面向对象编程 (OOP)</strong> ​。将现实世界的事物抽象为程序中的​<strong>对象</strong>​，每个对象包含​<strong>属性（状态）和行为（方法）</strong> 。</li>
<li>​<strong>程序世界</strong>：一个程序就是一个由许多对象构成的世界。</li>
</ul><section><h3 id="类与对象的关系">类与对象的关系</h3><ul>
<li>
<p>​<strong>类 (Class)</strong> ：</p>
<ul>
<li>抽象的、概念上的定义，代表一类事物（如“猫类”、“人类”）。</li>
<li>是​<strong>对象的模板/数据类型</strong>​，定义了该类对象共有的<strong>属性</strong>和​<strong>行为</strong>。</li>
</ul>
</li>
<li>
<p>​<strong>对象 (Object) / 实例 (Instance)</strong> ：</p>
<ul>
<li>具体的、实际存在的个体，是类的一个具体例子（如“一只叫小白3岁的猫”、“一个叫老韩的人”）。</li>
</ul>
</li>
<li>
<p>​<strong>关系</strong>​：​<strong>类是对象的抽象，对象是类的实例</strong>。必须先有类，才能创建对象。</p>
</li>
</ul></section><section><h3 id="对象在内存中的存在形式重要">对象在内存中的存在形式（重要！）</h3><p><img alt="" loading="lazy" decoding="async" width="1026" height="477" src="/media/be6faf64dd78.webp" srcset=""></p><ol>
<li>​<strong>栈</strong>：存放局部变量等（如对象引用 cat1）。</li>
<li>​<strong>堆</strong>：存放对象本身（属性数据）。</li>
<li>​<strong>方法区</strong>：存放类的信息（属性结构、方法代码）、常量池。</li>
</ol><ul>
<li>
<p>​<strong>创建流程</strong>​：Cat cat1 = new Cat();</p>
<ol>
<li>​<strong>加载类信息</strong>：JVM将Cat类的属性、方法信息加载到方法区（只加载一次）。</li>
<li>​<strong>堆中分配空间</strong>​：在堆中开辟内存，存放Cat对象的属性，并进行​<strong>默认初始化</strong>（如int为0，String为null）。</li>
<li>​<strong>建立引用</strong>：将堆中对象的地址（如0x0011）赋给栈中的引用变量cat1。</li>
<li>​<strong>指定初始化</strong>​：执行cat1.name = “小白”等语句，为属性赋具体值。</li>
</ol>
</li>
</ul></section><section><h3 id="属性--成员变量--字段">属性 / 成员变量 / 字段</h3><ul>
<li>
<p>​<strong>概念</strong>​：属性是类的一个组成部分，表示对象的状态或数据。成员变量 = 属性 = 字段 (field)。</p>
</li>
<li>
<p>​<strong>定义语法</strong>：访问修饰符 属性类型 属性名; （如 public String name;）</p>
</li>
<li>
<p>​<strong>注意事项</strong>：</p>
<ol>
<li>属性可以是任意类型（基本类型或引用类型如数组、对象）。</li>
<li>属性若不赋值，有默认值（规则同数组：int 0, double 0.0, boolean false, 引用类型 null）。</li>
</ol>
</li>
</ul></section><section><h3 id="类和对象的内存分配机制">类和对象的内存分配机制</h3><ul>
<li>​<strong>基本数据类型赋值</strong>​：传递的是​<strong>值本身</strong>​。int a = 10; int b = a; 修改b不影响a。</li>
<li>​<strong>引用数据类型赋值</strong>​：传递的是对象在​<strong>堆中的地址</strong>。</li>

<li>
<p>对象不仅有属性（状态），还有行为（功能）。方法用于封装对象的行为。</p>
</li>
<li>

<ol>
<li>​<strong>提高代码复用性</strong>：将常用功能封装成方法，多处调用。</li>
<li>​<strong>实现细节封装</strong>：使用者只需调用方法，无需关心内部实现。</li>
</ol>
</li>

<li>
<p><strong>概念</strong>：方法自己调用自己，每次调用传入不同的变量。</p>
</li>
<li>
<p><strong>能解决的问题</strong>：数学问题（阶乘、斐波那契数列）、迷宫、汉诺塔、八皇后、各种算法（快排、二分查找）等。</p>
</li>
<li>
<p><strong>重要规则</strong>：</p>
<ol>
<li>每次调用都会开辟新的栈空间，局部变量独立。</li>
<li>如果方法中使用引用类型变量，则会共享该数据。</li>
<li><strong>必须向退出递归的条件逼近</strong>，否则会无限递归导致栈溢出 (StackOverflowError)。</li>
<li>谁调用，结果就返回给谁。</li>
</ol>
</li>
<li>
<p></p><center><figure><img src="https://assets.b3logfile.com/siyuan/1725419116931/assets/network-asset-network-asset-image-20260302171935-i0ny4yg.png" alt=""><figcaption>image</figcaption></figure></center><p></p>
</li>
</ul></section><section><h3 id="5-方法重载-overload">5. 方法重载 (OverLoad)</h3><ul>
<li>
<p>​<strong>概念</strong>​：在同一个类中，允许存在多个​<strong>同名方法</strong>​，但要求它们的​<strong>形参列表不一致</strong>（类型、个数、顺序至少有一项不同）。</p>
</li>
<li>
<p>​<strong>好处</strong>：减轻起名和记名的麻烦。</p>
</li>
<li>
<p>​<strong>细节</strong>：</p>
<ol>
<li>方法名必须相同。</li>
<li>形参列表必须不同。<strong>返回类型、参数名称</strong>无要求。</li>
</ol>
</li>
<li>
<p>​<strong>判断</strong>：void show(int a, char b, double c) {}</p>
<ul>
<li>重载：void show(int a, double c, char b){} (顺序不同)</li>
<li>不重载：void show(int x, char y, double z){} (仅参数名不同，不算)</li>
</ul>
</li>
</ul></section><section><h3 id="6-可变参数">6. 可变参数</h3><ul>
<li>
<p>​<strong>概念</strong>：将同一个类中多个同名同功能但参数个数不同的方法，封装成一个方法。</p>
</li>
<li>
<p>​<strong>语法</strong>：访问修饰符 返回类型 方法名(数据类型… 形参名) {}</p>
</li>
<li>
<p>​<strong>细节</strong>：</p>
<ol>
<li>实参可以为0个到任意多个。</li>
<li>可变参数的实参可以是数组。</li>
<li>​<strong>本质就是数组</strong>。</li>
<li>可变参数必须放在形参列表的​<strong>最后</strong>，且一个形参列表只能有一个可变参数。</li>
</ol>
</li>

<section><h2 id="三作用域">三、作用域</h2><section><h3 id="1-基本概念">1. 基本概念</h3><ul>
<li>​<strong>全局变量（属性）</strong> ：作用域为整个类体，可以被本类方法使用，也可通过对象被其他类使用。有默认值，生命周期长（伴随对象）。</li>
<li>​<strong>局部变量</strong>：作用域在定义它的代码块（如方法、循环体内）内。必须赋值后才能使用，无默认值。生命周期短（伴随代码块执行）。</li>
</ul></section><section><h3 id="2-注意事项">2. 注意事项</h3><ol>
<li>​<strong>属性和局部变量可以重名</strong>​，访问时遵循​<strong>就近原则</strong>。</li>
<li>同一作用域内（如一个方法内），局部变量不能重名。</li>
<li>​<strong>修饰符</strong>：属性可以加public、private等修饰符，局部变量不能加。</li>
</ol></section></section>
<section><h2 id="四构造器--构造方法">四、构造器 / 构造方法</h2><section><h3 id="1-为什么需要构造器">1. 为什么需要构造器</h3><p>在创建对象时，直接完成对象的初始化（为属性赋初值），而不是先创建空对象再赋值。</p></section><section><h3 id="2-基本介绍">2. 基本介绍</h3><ul>
<li>
<p>构造器是类的一种特殊方法，主要作用是​<strong>完成新对象的初始化</strong>。</p>
</li>
<li>
<p>​<strong>特点</strong>：</p>
<ol>
<li>方法名必须和类名相同。</li>
<li>​<strong>没有返回值</strong>，也不能写void。</li>
<li>在创建对象时，系统<strong>自动调用</strong>相应的构造器。</li>
</ol>
</li>
<li>
<p>​<strong>语法</strong>：[修饰符] 方法名(形参列表) { 方法体; }</p>
</li>
</ul></section><section><h3 id="3-注意事项">3. 注意事项</h3><ol>
<li>一个类可以定义多个不同的构造器（即构造器重载）。</li>
<li>如果没有定义构造器，系统会生成一个​<strong>默认的无参构造器</strong>。一旦定义了自己的构造器，默认构造器就被覆盖，除非显式定义。</li>
<li>构造器可以完成除了初始化之外的任何操作（如调用方法），但​<strong>不推荐</strong>。</li>
</ol></section></section>

<section><h2 id="七封装-encapsulation">七、封装 (Encapsulation)</h2><section><h3 id="1-封装的理解与好处">1. 封装的理解与好处</h3><ul>
<li>
<p>​<strong>理解</strong>：将数据和操作数据的方法封装在一起，对外隐藏实现细节。</p>
</li>
<li>
<p>​<strong>好处</strong>：</p>
<ol>
<li>​<strong>隐藏实现细节</strong>：使用者只需关注功能，无需了解内部复杂逻辑。</li>
<li>​<strong>数据验证</strong>：可以对数据进行有效性的校验，保证数据安全合理。</li>
<li>​<strong>便于维护</strong>：内部逻辑修改不影响外部调用。</li>
</ol>
</li>
</ul></section><section><h3 id="2-封装的实现步骤-三步">2. 封装的实现步骤 (三步)</h3><ol>
<li>​<strong>私有化属性</strong>：将属性用private修饰。</li>
<li><strong>提供公共的set方法</strong>：用于对属性进行判断和赋值。</li>
<li><strong>提供公共的get方法</strong>：用于获取属性的值。</li>
</ol></section></section>
<section><h2 id="八继承-inheritance">八、继承 (Inheritance)</h2><section><h3 id="1-为什么需要继承">1. 为什么需要继承？</h3><p>解决多个类中存在<strong>相同属性和方法</strong>时的<strong>代码复用</strong>问题。</p></section><section><h3 id="2-继承的基本介绍与示意图">2. 继承的基本介绍与示意图</h3><ul>
<li>​<strong>概念</strong>：子类 (Subclass) 继承父类 (Superclass) 的属性和方法，同时可以拥有自己的特性。</li>
<li>​<strong>语法</strong>：class 子类 extends 父类 { }</li>
<li>​<strong>术语</strong>：父类（超类、基类）、子类（派生类）。</li>
</ul></section><section><h3 id="3-继承的细节问题-非常重要">3. 继承的细节问题 (非常重要！)</h3><ol>
<li>
<p>​<strong>访问权限</strong>​：子类继承了父类<strong>所有</strong>的属性和方法。但​<strong>私有(private)成员不能在子类直接访问</strong>，需要通过父类提供的公共方法间接访问。</p>
</li>
<li>
<p>​<strong>构造器调用</strong>：</p>
<ul>
<li>创建子类对象时，<strong>必须调用父类构造器</strong>以完成父类初始化。</li>
<li>默认情况下，子类构造器会<strong>隐式调用父类的无参构造器</strong> super()。</li>
<li>如果父类​<strong>没有无参构造器</strong>​，则必须在子类构造器中<strong>显式使用super(参数)</strong>  指定调用父类的哪个构造器，且super(…)必须是子类构造器的​<strong>第一条语句</strong>。</li>
</ul>
</li>
<li>
<p>​<strong>单继承机制</strong>​：Java中，一个子类​<strong>最多只能直接继承一个父类</strong>（单继承）。</p>
</li>
<li>
<p>​<strong>Object类</strong>：Java中所有类都默认继承Object类。</p>
</li>
<li>
<p>​<strong>super关键字</strong>​：代表​<strong>父类的引用</strong>，用于访问父类的属性、方法和构造器。</p>
<ul>
<li>super.属性名 / super.方法名()：访问父类的成员（不能访问private）。</li>
<li>super(参数列表)：在子类构造器中调用父类构造器。</li>
</ul>
</li>
<li>
<p>​<strong>继承的内存布局</strong>​：子类对象在堆中包含了父类所有属性的空间。属性查找顺序：​<strong>子类 -></strong>  <strong>父类 -></strong>   <strong>… -></strong>  <strong>Object</strong>。</p>
</li>
</ol></section><section><h3 id="4-super-与-this-的比较">4. super 与 this 的比较</h3>

<table><thead><tr><th>区别点</th><th>this</th><th>super</th></tr></thead><tbody><tr><td><strong>访问属性</strong></td><td>从<strong>本类</strong>开始查找</td><td>从<strong>父类</strong>开始查找</td></tr><tr><td><strong>调用方法</strong></td><td>从<strong>本类</strong>开始查找</td><td>从<strong>父类</strong>开始查找</td></tr><tr><td><strong>调用构造器</strong></td><td>调用<strong>本类</strong>构造器 (this(…))</td><td>调用<strong>父类</strong>构造器 (super(…))</td></tr><tr><td><strong>特殊</strong></td><td>表示<strong>当前对象</strong></td><td>在子类中访问<strong>父类对象</strong></td></tr></tbody></table><p>​<strong>注意</strong>​：super(…)和this(…)都​<strong>必须放在构造器第一行</strong>，因此二者不能共存于同一个构造器中。</p></section></section>
<section><h2 id="九多态-polymorphism">九、多态 (Polymorphism)</h2><section><h3 id="1-多态的基本介绍">1. 多态的基本介绍</h3><ul>
<li>
<p>​<strong>概念</strong>​：方法或对象具有​<strong>多种形态</strong>。建立在封装和继承的基础之上。</p>
</li>
<li>
<p>​<strong>体现</strong>：</p>
<ol>
<li>​<strong>方法的多态</strong>​：<strong>重载 (Overload)</strong>  和 ​<strong>重写 (Override)</strong> 。</li>
<li>​<strong>对象的多态 (核心)</strong> ​：一个对象的<strong>编译类型</strong>和<strong>运行类型</strong>可以不一致。</li>
</ol>
</li>
</ul></section><section><h3 id="2-对象的多态-核心">2. 对象的多态 (核心)</h3><ul>
<li>
<p>​<strong>重要规则</strong>：</p>
<ol>
<li>对象的<strong>编译类型</strong>在定义时 (=左边) 就确定了，不能改变。</li>
<li>对象的<strong>运行类型</strong>是可以变化的 (=右边)。</li>
<li>编译时看左边，运行时看右边。</li>
</ol>
</li>
</ul><div class="expressive-code"><figure class="frame"><figcaption class="header"></figcaption><pre data-language="java"><code><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">1</div></div><div class="code"><span style="--0:#E5C07B;--1:#885D01">Animal</span><span style="--0:#E6888F;--1:#AF4238"> animal </span><span style="--1:#383A42"><span style="--0:#56B6C2">=</span><span style="--0:#E6888F"> </span></span><span style="--0:#CD89E1;--1:#A626A4">new</span><span style="--0:#E6888F;--1:#383A42"> </span><span style="--0:#61AFEF;--1:#3360C1">Dog</span><span style="--1:#383A42"><span style="--0:#E6888F">()</span><span style="--0:#ABB2BF">;</span><span style="--0:#E6888F"> </span></span><span style="--0:#9FA3AA;--0fs:italic;--1:#646568;--1fs:italic">// animal编译类型Animal，运行类型Dog</span></div></div><div class="ec-line"><div class="gutter"><div class="ln" aria-hidden="true">2</div></div><div class="code"><span style="--1:#383A42"><span style="--0:#E6888F">animal </span><span style="--0:#56B6C2">=</span><span style="--0:#E6888F"> </span></span><span style="--0:#CD89E1;--1:#A626A4">new</span><span style="--0:#E6888F;--1:#383A42"> </span><span style="--0:#61AFEF;--1:#3360C1">Cat</span><span style="--1:#383A42"><span style="--0:#E6888F">()</span><span style="--0:#ABB2BF">;</span><span style="--0:#E6888F"> </span></span><span style="--0:#9FA3AA;--0fs:italic;--1:#646568;--1fs:italic">// animal运行类型变为Cat，编译类型仍是Animal</span></div></div></code></pre><div class="copy"><div aria-live="polite"></div><button title="Copy to clipboard" data-copied="Copied!" data-code="Animal animal = new Dog(); // animal编译类型Animal，运行类型Doganimal = new Cat(); // animal运行类型变为Cat，编译类型仍是Animal"><div></div></button></div></figure></div></section><section><h3 id="3-多态的向上转型与向下转型">3. 多态的向上转型与向下转型</h3><ul>
<li>
<p>​<strong>向上转型</strong>：</p>
<ul>
<li>本质：​<strong>父类的引用指向子类的对象</strong>。</li>
<li>语法：父类类型 引用名 = new 子类类型();</li>
<li>特点：可以调用父类中的所有成员（遵守访问权限），​<strong>不能调用子类特有成员</strong>​；运行效果看子类的具体实现（即​<strong>动态绑定</strong>）。</li>
</ul>
</li>
<li>
<p>​<strong>向下转型</strong>：</p>
<ul>
<li>本质：将<strong>父类引用</strong>强制转回​<strong>子类引用</strong>。</li>
<li>语法：子类类型 引用名 = (子类类型) 父类引用;</li>
<li>前提：父类引用<strong>必须指向</strong>当前要转换的​<strong>子类类型对象</strong>。否则会抛出ClassCastException。</li>
<li>作用：转型后可以调用子类的所有成员。</li>
</ul>
</li>
<li>
<p>​<strong>instanceof比较操作符</strong>​：用于判断<strong>对象的运行类型</strong>是否为XX类型或其子类型。对象 instanceof 类名</p>
</li>
</ul></section><section><h3 id="4-java的动态绑定机制-非常重要">4. Java的动态绑定机制 (非常重要！)</h3><ol>
<li>​<strong>调用对象方法时</strong>​：该方法会和对象的<strong>内存地址/运行类型</strong>进行绑定。</li>
<li>​<strong>调用对象属性时</strong>​：<strong>没有</strong>动态绑定机制，属性值取决于​<strong>声明该属性的类型</strong>（即编译类型）。</li>
</ol></section><section><h3 id="5-多态的应用">5. 多态的应用</h3><ol>
<li>​<strong>多态数组</strong>：数组定义为父类类型，实际存放子类类型的对象。</li>
<li>​<strong>多态参数</strong>：方法形参定义为父类类型，实参可以传入任意子类类型的对象。极大地提高了代码的复用性和扩展性。</li>
</ol></section></section>
<section><h2 id="十方法重写覆盖-override">十、方法重写/覆盖 (Override)</h2><section><h3 id="1-基本介绍">1. 基本介绍</h3><p>子类有一个方法，和父类的某个方法的​<strong>名称、返回类型、参数列表完全一样</strong>​，我们就说子类的这个方法<strong>重写 (覆盖)</strong>  了父类的方法。</p></section><section><h3 id="2-注意事项与细节">2. 注意事项与细节</h3><ol>
<li>子类方法的<strong>形参列表、方法名称</strong>必须和父类方法完全一致。</li>
<li>子类方法的<strong>返回类型</strong>必须和父类方法一样，或者是父类返回类型的​<strong>子类</strong>。</li>
<li>子类方法的<strong>访问权限</strong>不能比父类方法更严格（即不能缩小访问范围）。例如：父类是public，子类不能是protected。</li>
<li>子类不能重写父类的private方法。</li>
<li>​<strong>重写(Override) vs 重载(Overload)</strong> ：</li>
</ol>

<section><h2 id="十一object-类详解">十一、Object 类详解</h2><p>Object类是Java所有类的根父类。</p><section><h3 id="1-equals-方法">1. equals 方法</h3><ul>
<li>
<p>​ <strong>==</strong>  <strong>操作符</strong>：</p>
<ul>
<li>判断​<strong>基本类型</strong>​：比较<strong>值</strong>是否相等。</li>
<li>判断​<strong>引用类型</strong>​：比较<strong>地址</strong>是否相等（是否为同一个对象）。</li>
</ul>
</li>
<li>
<p>​<strong>equals 方法</strong>：</p>
<ul>
<li>是Object类中的方法，只能判断​<strong>引用类型</strong>。</li>
<li><strong>默认</strong>行为：判断<strong>地址</strong>是否相等 (return (this == obj);)。</li>
<li>​<strong>子类重写</strong>​：如String、Integer、Date等类重写了equals方法，用于判断<strong>内容</strong>是否相等。</li>
<li>​<strong>如何重写equals</strong>：通常比较两个对象的所有属性是否都相等。</li>
</ul>
</li>
</ul></section><section><h3 id="2-hashcode-方法">2. hashCode 方法</h3><ul>
<li>返回对象的哈希码值（整数），支持哈希表类（如HashMap）的高效运行。</li>
<li>两个引用指向​<strong>同一个对象</strong>，哈希值肯定相同。</li>
<li>两个引用指向​<strong>不同对象</strong>​，哈希值​<strong>一般不同</strong>（哈希值主要根据地址计算，但不完全等于地址）。</li>
<li>在集合中，如果需要重写equals方法，通常也需要重写hashCode方法。</li>
</ul></section><section><h3 id="3-tostring-方法">3. toString 方法</h3><ul>
<li>​<strong>默认返回</strong>：全类名 + @ + 哈希值的十六进制字符串。</li>
<li>​<strong>子类重写</strong>​：通常返回对象的​<strong>属性信息</strong>。</li>
<li>​<strong>自动调用</strong>：当直接输出对象 (System.out.println(对象)) 或拼接对象时，会自动调用该对象的toString()方法。</li>
</ul></section><section><h3 id="4-finalize-方法-已过时了解即可">4. finalize 方法 (已过时，了解即可)</h3><ul>
<li>当对象被垃圾回收器回收时，系统会自动调用该方法。</li>
<li>子类可以重写它，用于释放资源（如关闭文件、数据库连接）。</li>
<li>​<strong>注意</strong>：实际开发中几乎不会使用，垃圾回收由JVM管理，不建议主动调用System.gc()。</li>
</ul></section></section>
